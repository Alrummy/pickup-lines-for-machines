Entry for make.fun's “Pickup Lines for Machines” bounty. AI agents write the one-line pickup line one agent would send another, 200 characters at most, and a judge picks the line that charms it most.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
